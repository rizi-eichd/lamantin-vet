# Зоопрофи

Многостраничный сайт ветеринарной клиники в Мытищах. Next.js App Router, React, TypeScript, Tailwind CSS, shadcn/ui-compatible Button/Dialog на Radix, Lucide, Motion, React Hook Form, Zod. Есть десять страниц услуг, форма записи и серверная доставка заявок через Telegram.

Публичный сайт: **https://vivasik228.github.io/zooprofi/**.

GitHub Pages публикует статическую версию со всеми страницами и интерактивными элементами. На этом хостинге нет серверного обработчика: форма сообщает, что онлайн-запись пока не подключена, и предлагает телефон клиники. Обычная серверная сборка сохраняет доставку через Telegram после настройки секретов.

Главная переработана как фотообложка с крупным названием, каталогом услуг и асимметричным разворотом фотографий. Её отдельная система описана в `HOME-DESIGN.md` и `.impeccable/home-design.json`; `DESIGN.md` сохраняет оформление остальных страниц. Проверки и независимый вердикт: `docs/photo-cover-verification.md`.

## Запуск

Нужны Node.js 22.13+ (рекомендуется 24 LTS) и pnpm 11. Версии зависимостей зафиксированы в `pnpm-lock.yaml`; совместимые версии ESLint/TypeScript выбраны по peer dependencies.

```sh
pnpm install --frozen-lockfile
cp .env.example .env.local
pnpm dev
```

На Windows вместо `cp` можно использовать `Copy-Item .env.example .env.local`. Откройте http://localhost:3000. Настройки `.env.local` не коммитятся.

```sh
pnpm test
pnpm typecheck
pnpm lint
pnpm build
pnpm start
```

## Telegram

1. Создайте бота через официальный @BotFather, получите токен.
2. Откройте чат с ботом, нажмите Start. Для группы добавьте бота в административный чат и отправьте там сообщение.
3. Получите ID целевого чата через Bot API `getUpdates` в локальном инструменте. Не публикуйте URL с токеном и не передавайте токен клиентскому коду.
4. Укажите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env.local` или секретах хостинга. Перезапустите сервер.
5. Отправьте тестовую заявку после согласования юридических условий. Убедитесь, что она дошла в нужный административный чат. Бот должен иметь право отправлять сообщения.

API `/api/booking` возвращает успех только при HTTP-успехе и `ok: true` от Telegram. Без секретов возвращает 503 и предлагает позвонить; при отказе/таймауте — 502. Время в заявке является желаемым и всегда требует подтверждения. Заявки не сохраняются в собственной базе; автоматических повторных отправок нет, поэтому после сетевого таймаута возможна неопределённость доставки. Перед повторной отправкой проверьте административный чат, чтобы избежать дубля.

## Редактирование

- `src/data/contacts.ts`: адрес, телефон, карта, график (`hours: null` до подтверждения).
- `src/data/services.ts`: направления, тексты, подготовка, `enabled`, `availability`. Карточка Яндекс указывает несколько направлений; перед публикацией подтвердите актуальность каждого.
- `src/data/prices.ts`: актуальные цены; `null` отображается как «Уточняйте по телефону». Внесите суммы после подтверждения владельцем.
- `src/data/team.ts`: массив специалистов с реальными ФИО, специализацией, описанием и локальной фотографией; пустой массив показывает нейтральный блок.
- `src/data/reviews.ts`: подтверждённые отзывы с разрешением автора и ссылкой на источник; публикуются только записи `verified: true`.
- `src/data/faq.ts`: организационные вопросы.
- `public/images`: реальные фотографии из указанной пользователем карточки Яндекс; происхождение записано в `SOURCES.md`. Заменяйте файлами владельца при необходимости. Админ-панель и загрузчик не включены; данные редактируются в проекте.

## Развёртывание

Для приёма заявок используйте Node.js-хостинг с поддержкой Next.js (например Vercel или собственный сервер). Задайте HTTPS-домен в `NEXT_PUBLIC_SITE_URL` **перед сборкой**, секреты Telegram — на сервере. На Vercel используются стандартные команды Next.js; на своём сервере — `pnpm build` и `pnpm start` за HTTPS reverse proxy.

Для публичного просмотра через GitHub Pages выполните `pnpm build:pages`. Скрипт собирает отдельную копию в `.pages-build/`, исключает серверный API из этой копии и сохраняет путь к готовому экспорту в `.pages-build/latest.json`. Исходный API остаётся в проекте. Экспорт содержит `.nojekyll` и публикуется в ветке `gh-pages`; в настройках Pages выбран источник `gh-pages`, каталог `/`. Путь `/zooprofi` учитывается в ссылках, изображениях и клиентской навигации.

Для доступа извне на собственном сервере запустите `pnpm exec next start --hostname 0.0.0.0` за настроенным reverse proxy; локальная команда по умолчанию слушает только loopback.

Антиспам: honeypot, минимальное время заполнения, валидация на сервере, лимит 5 запросов за 10 минут, ограничение тела 16 KB, проверка Origin. In-memory лимит подходит для одного процесса; на serverless/нескольких экземплярах настройте `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` (атомарный Redis-счётчик). За reverse proxy нужно перезаписывать входящий `x-forwarded-for`, не доверять пользовательскому заголовку. При отказе настроенного Redis API закрывается с 503. Рекомендуется также лимит на уровне хостинга.

Не включайте журналирование тела запросов и секретов. Ограничьте доступ к чату заявок. Автотесты используют подмену сетевого транспорта, реальных сообщений не отправляют.

## Перед публичным запуском

- Подтвердите график, услуги, цены и данные сотрудников.
- Проверьте права на фотографии из Яндекс Карт либо используйте свои оригиналы.
- Заполните юридическое имя оператора, реквизиты, контакт для обращений, сроки хранения и обработчиков в `/privacy` и `/consent`. Сейчас это явные черновики, а не готовые юридические документы. Согласуйте инфраструктуру и обработку заявок через Telegram.
- Настройте Telegram и проверьте реальную доставку.
- Укажите реальный домен, проверьте контакты, форму и мобильные размеры.
- После готовности задайте `SITE_INDEXABLE=true` и пересоберите сайт. По умолчанию индексирование отключено, чтобы черновики не попадали в поиск.

SEO: metadata, canonical, OG, sitemap, robots, VeterinaryCare JSON-LD без выдуманных рейтингов/врачей/часов работы. Фото локальные WebP через Next Image; шрифт поставляется локально. Анимации учитывают reduced motion. Реальные Core Web Vitals измеряйте после запуска на выбранном хостинге.
