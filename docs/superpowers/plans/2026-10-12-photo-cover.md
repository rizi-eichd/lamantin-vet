# Homepage photo cover

The latest user brief asks for a new art direction, autonomous implementation, retained phrases and genuine clinic information. It supersedes the title-over-split-stage concept. Keep the existing Next.js stack, shared navigation, other pages, form and API.

## Three directions considered

1. A photographic cover: oversized clinic name, one uninterrupted cat-and-dog panorama, location and booking in a separate reading band. Strongest emotional identification; the actual photograph creates the remembered moment. Chosen.
2. A clinical register: dense typographic index with the services directly in the opening. Clear and fast, but too close to the recently built disclosure catalogue and insufficiently photographic.
3. An entrance-first architectural composition: large real facade photograph, address-led heading, small pharmacy photograph. Specific to this clinic, but the ordinary entrance photograph cannot carry the requested first-screen impact by itself.

## Contract

THESIS: a clinic cover in which the real animals and the clinic's name occupy one uninterrupted visual field. No text-left/image-right hero, rounded feature grid or fabricated proof.

OWN-WORLD: forest #223f37, cream #f7f5f0, sage #e4e9e2, muted #4d6258. Large self-hosted Manrope 500 clinic lettering; quieter 400/500 text. One wide rectangular photograph, no gradient or glass overlay.

FIRST VIEWPORT: cream brand lettering above a full-width panorama in one forest cover. Service purpose and location beside the lettering, separate action band under the photo. On mobile the name wraps deliberately into two lines and both animal faces stay visible.

STORY: cover → interactive services catalogue → asymmetric real photo spread → visit sequence → honest trust information → prices → booking and practical contact information.

INTERACTION: one photo aperture entrance; responsive functional hover and disclosure feedback. Reduced-motion displays the final frame. No hidden content, cursor tricks or scroll hijacking.

FORM: code-led, no approved pixel comp; supplied photos retained as photographs. Homepage scope overrides the old shared visual direction on this surface; other routes preserve global DESIGN.md.

FINISH: review actual desktop/mobile evidence, fix material findings, document scoped tokens and source preservation, update the source archive.
