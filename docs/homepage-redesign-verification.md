# Проверка нового дизайна главной страницы

Дата: 11 октября 2026.

## Область изменений

Изменён `src/app/page.tsx`, добавлены `src/app/home.module.css` и `src/components/home-motion.tsx`. Общие стили, layout, header/footer, данные, страницы услуг, запись и юридические страницы не менялись.

Новая композиция: типографический первый экран, сгруппированный каталог услуг, последовательность подготовки к визиту, фотографии клиники на тёмном фоне, открытый прайс, терракотовый блок записи, FAQ, фотография здания рядом с контактами, форма на светлом листе. Используются существующие настоящие фотографии. Все исходные русские слова сохранены; новых отзывов, врачей, цен или достижений нет.

## Проверки

- `pnpm build`: успешно, TypeScript и генерация всех 20 страниц завершены.
- `pnpm lint`: без ошибок.
- `pnpm test`: 22/22 успешно.
- SHA256 семи защищённых файлов (globals, layout, booking page, header, footer, booking form, price list) совпадает с исходным состоянием.
- Счётчики русских слов `page-before.tsx` и обновлённого `page.tsx` совпадают.
- SSR отдаёт содержимое с `data-home-enhanced="false"`; по умолчанию секции видимы. На маршрутах booking, consultation, privacy, consent отсутствует оболочка главной страницы.
- В браузере проверены ширины 320, 375, 768, 1024, 1920 px. Горизонтального переполнения текста, ссылок, кнопок и полей нет.
- Проверены мобильное меню, переходы к секциям, поиск «УЗИ», фильтр «Профилактика», раскрытие FAQ, семь сообщений при отправке пустой формы.
- Ссылка записи на вакцинацию открывает `/booking?service=vaccination` с выбранной услугой. Отдельная страница консультации использует прежнее оформление.
- Консоль браузера: ошибок и предупреждений не зафиксировано.
- Независимая проверка исходников завершена. Удалён неиспользуемый атрибут состояния reduced-motion, способный различаться при гидратации.

## Анимации

Поэтапное появление типографики и секций, прорисовка контуров, небольшой параллакс фотографии на устройствах с точным указателем, движение стрелок при наведении, индикатор прокрутки. Эффекты включаются после гидратации; observer отключается при размонтировании. CSS `prefers-reduced-motion` отключает движение и оставляет содержимое видимым. Режим reduced-motion проверен по исходникам, без переключения системной настройки пользователя.

Реальные заявки и сообщения в Telegram при проверке не отправлялись. Настройка доставки заявок не входила в изменение дизайна.

Снимки итогового дизайна находятся рядом с проектом: `home-atlas-desktop.png`, `home-atlas-services.png`, `home-atlas-mobile.png`.
