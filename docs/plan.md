# Здоровый питомец — проект и план

Основание: полное техническое задание пользователя от 11.10.2026. Исполнение прямо авторизовано; отдельная публикация не запрошена.

Концепция: тёплая редакционная композиция, молочный фон, зелёная типографика, оранжевые CTA. По уточнению пользователя фотографии взяты из карточки Яндекс Карт; сгенерированное изображение не используется. Врачи, отзывы и график не подменяются выдумкой.

1. Создать Next.js/React/TypeScript проект с Tailwind, shadcn primitives, Motion, RHF/Zod. Зафиксировать разрешённые версии lockfile.
2. Отдельные контакты, услуги, FAQ, цены, специалисты, отзывы. Каждый из десяти маршрутов услуг получает описание, подготовку без медицинских назначений и уточнение доступности.
3. Тесты серверного контракта до реализации: неверный телефон/согласие/дата, отсутствие Telegram, отказ Telegram, успех, honeypot, лимит, неизвестная услуга, большой запрос, чужой origin. Общая схема для браузера и API. Секреты только серверные.
4. Главная: hero, услуги, преимущества, клиника, специалисты, цены с поиском/категориями, подтверждённые отзывы/ссылка Яндекс, FAQ, контакты. Страницы записи и юридических черновиков. Header/mobile nav, footer, CTA.
5. SEO metadata, OG, JSON-LD, robots/sitemap, 404; запрет индексации до подтверждения. Accessibility, reduced motion, адаптивность 320–1920.
6. Проверить тесты, TypeScript, ESLint, production build. Локально проверить маршруты, форму, фильтры и мобильные размеры; исправить найденные дефекты. Независимый обзор API и интерфейса.

Проверка рисков: заявка никогда не объявляется доставленной при отсутствии токена или отказе Telegram; время только желаемое; цена отсутствует без источника; секреты не уходят клиенту; спам ограничивается; юридические данные остаются блокером публичного запуска.
